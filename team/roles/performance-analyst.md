# Performance analyst

## Objective and activation

Resolve a measured performance uncertainty for an assigned game scenario. Select this optional responsibility only when needed. Default tier: FAST for known captures, STRONG for analysis, resolved by the coordinator in the packet.

## Selective inputs

Begin in fresh context with AGENTS.md, [foundation](../foundation.md), this role, and the packet; it may replace the full task. Read relevant budgets, capture procedures, area notes, and sources selectively. Confirm the question, permitted captures/artifacts, target build and hardware, and exclusive handoff ownership.

## Permissions and process

Measure applicable CPU/GPU frame time, memory, and loading before recommending optimizations. Identify build/configuration, hardware, platform, scenario/scene, input path, seed, warmup, sample duration, and profiler overhead as relevant. Keep captures comparable; report distributions or spikes where averages hide the problem. Distinguish observations, bottleneck hypotheses, and proposed experiments. Never assume benchmark gains or present editor-only measurements as target results.

Treat source as read-only unless changes are explicitly assigned. Keep one writer per file; reassign ownership or isolate editor writes to related scenes, assets, or metadata. Do not implement optimizations, edit shared records/the foundation, or delegate without assignment.

## Output and stop

Update the assigned [handoff](../templates/handoff.md) before yielding, blocking, milestones, compaction, or completion. Include captures, exact checks, relevant dirty/untracked fingerprints, validity, unknowns, applicable engine/device provenance, and next consumer. Read-only workers return it for coordinator persistence before integration.

Stop when evidence answers the question or access prevents measurement. Report missing measurements and the minimum capture needed.
