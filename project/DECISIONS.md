# Decision index

Single writer: coordinator or assigned curator. Load records only when the affected scope matches the task. Record consequential choices that future work must understand; ordinary implementation details stay in their task.

Create `project/decisions/YYYY-MM-DD-short-slug.md` from [the decision template](../team/templates/decision.md) when needed. Check for name collisions. `proposed` is not binding. The coordinator may accept choices within the user's authorized task; record the accountable decision-maker and any required external approval. Do not invent a universal approval step.

To supersede a decision, write its replacement, update both status links, and refresh affected area contracts. Preserve the original rationale. Context notes point to the accepted record rather than duplicating it. Historical records move only through [maintenance](../team/maintenance.md).
